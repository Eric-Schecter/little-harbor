Little Harbor / 小小港湾 — Web build

本地运行：
1. 解压整个 ZIP，保持所有文件在同一目录。
2. 在该目录运行 python3 -m http.server 8795
3. 浏览器打开 http://localhost:8795，加载完成后点击中央游戏封面。
不要通过 file:// 直接双击 HTML；浏览器会阻止加载 WASM/资源包。

静态托管：
上传本目录全部文件到支持 HTTPS 的静态网站，入口 index.html。
单线程构建，不需要设置跨源隔离响应头。服务器应将 .wasm 作为 application/wasm 提供。
推荐现代桌面浏览器，需支持 WebGL 2。声音由开始游戏的点击手势启用。

操作：
拖动/点选两座相同炮塔合成；Q/W/E 建造弩、投石、火油。
G 后点击海面释放落石；O 号角；U 工坊；空格下一波；P/Esc 暂停。
暂停菜单可继续、重玩；网页版“退出游戏”返回启动页。
右下角扬声器按钮切换声音。最高波次保存在浏览器本地，清理网站数据会清除记录。

此导出保留当前确认的休闲 BGM、八级炮塔和港湾玩法。
参考游戏的图像、音频、参考场景、原始 bundle 均已移除。
美术、音效与开源字体来源见 THIRD_PARTY.txt 和 licenses/。
